# RT-BE50: справочник по настройкам

Неофициальный путеводитель по веб-интерфейсу роутера **ASUS RT-BE50**, на русском. Для каждой страницы и поля: что это значит простыми словами, как это называют в других местах и куда идти за подробностями.

Справочник **не пересказывает** руководство ASUS. Его ценность в связке: короткое объяснение для не-технаря, ссылки на официальные статьи и на общие знания (как в хорошей книге-путеводителе, которая рассказывает по верхам и показывает, где копать глубже).

- Сайт: <https://rt-be50.netlify.app> (зеркало: <https://rt-be50.volkov.ru.net>)
- Проверено на: RT-BE50, прошивка ASUS 3.0.0.6.102_58636
- Не путайте: BE3600 это класс скорости Wi-Fi 7, а не модель. RT-BE3600 (он же RT-BE58U) это другой роутер.

## Как устроена страница

Оформление повторяет веб-интерфейс самого роутера (Asuswrt): шапка, строка статуса, меню слева, вкладки, таблицы полей и полоса с кнопками внизу. Справочник открывают на одном экране, роутер на другом, и нужное место узнаётся с первого взгляда. Цвета взяты из CSS роутера и записаны в OKLCH (`src/styles/tailwind.css`); акцентные чуть насыщеннее, в пространстве Display P3.

Меню, вкладки, пути в меню и адреса страниц роутера (`.asp`) описаны в одном месте: `src/data/menu.ts`. Каждая вкладка роутера это `page.mdx` в `src/app/<раздел>/<вкладка>/`.

| Блок | Зачем |
|---|---|
| `# Wireless - General` | Заголовок как в роутере. Над ним путь в меню (`Advanced Settings › Wireless › General`), рядом кнопка «Открыть в роутере» |
| `HowToSearch` | Как это называется в интерфейсе, как ещё называют, готовые поисковые запросы |
| `## Раздел` | Серая полоса-заголовок, как у таблиц роутера |
| `Fields` / `Field` | Поля списком `<dl>` в виде таблицы роутера: имя как в роутере, `aka`, макет элемента (список, переключатель, радиокнопки), рекомендуемое значение жёлтым |
| `Note` | Заметка: `tone="warn" \| "ok" \| "bad" \| "info"` |
| `K`, `Path`, `T`, `Sym` | Кнопки и пункты меню как `<kbd>`, путь в меню, сокращения с подсказкой `<abbr>` из `src/data/glossary.ts`, символ вместо слова с текстом для скринридера |
| `Related` | «Читать дальше»: официальные статьи ASUS, объяснения идеи (сначала на русском), соседние страницы |
| `Measure` / `Item` | Пункт чеклиста: где в роутере, что делает, плюсы, минусы, источники (`src/app/checklist/page.mdx`) |

Поиск по `⌘K` (FlexSearch) индексирует заголовки, текст и каждое `<Field>`, поэтому поле находится и по английскому названию из интерфейса, и по русскому синониму из `aka`.

## Как добавить страницу

1. Впишите вкладку в `src/data/menu.ts` (название как в роутере, адрес `.asp` из `menuList` в консоли страницы роутера).
2. Создайте `src/app/<раздел>/<вкладка>/page.mdx` по образцу `src/app/wireless/general/page.mdx`.
3. Ссылки в `Related` проверяйте: каждая должна отвечать 200 и вести на ту самую статью. Русские источники в приоритете; старые адреса справки Keenetic не работают, их русская справка теперь на support.netcraze.ru.

Правило содержания: не переписывать то, что хорошо объяснено у ASUS. Коротко объяснить, что это и что обычно выбирать, и дать ссылку.

## Запуск

```sh
npm install
npm run dev        # http://localhost:3000
npm run build      # статический сайт в out/
npm start          # посмотреть out/ локально
npm run card       # пересобрать public/share-card.jpg и иконку (после build)
```
