# WAN - DMZ

Все входящие подключения, которые не попали под другие правила, роутер отдаёт одному устройству. Оно оказывается в интернете почти без защиты. Это не «демилитаризованная зона» из офисных сетей, а грубый способ «открыть всё». {{ className: 'lead' }}

<Note tone="bad">
  Устройство в DMZ доступно из интернета на всех портах. Иногда так делают для игровой приставки, но лучше открыть только нужные порты: <Path items={['WAN', 'Virtual Server / Port Forwarding']} />.
</Note>

<HowToSearch queries={["dmz в роутере что это опасно"]}>
  DMZ‑хост, exposed host, «открыть все порты на один компьютер».
</HowToSearch>
