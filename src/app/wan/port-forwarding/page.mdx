# WAN - Virtual Server / Port Forwarding

Проброс портов: запрос из интернета на определённый порт роутер передаёт определённому устройству дома. Так делают доступ к домашнему серверу, NAS или камере снаружи. Каждое правило — дверь из интернета в домашнюю сеть. {{ className: 'lead' }}

<Note>
  Проброс не сработает, если у роутера серый адрес: WAN IP начинается с `10.`, `100.64`–`100.127`, `172.16`–`172.31` или `192.168.`. Тогда перед вами ещё один <T>NAT</T> — модем или сеть провайдера. Внешний адрес проверяют в <Path items={['Network Map']} />.
</Note>

Проброс работает только для IPv4. Внешний адрес с пробросом открывается и изнутри дома (NAT loopback включён всегда).

Безопаснее всего ничего не пробрасывать, а заходить домой через VPN: <Path items={['VPN', 'VPN Server']} />. Тогда наружу открыт один хорошо защищённый вход, а не каждый сервис.
