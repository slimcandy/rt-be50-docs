# Wireless - Roaming Block List

Список устройств, которые не должны переходить между узлами <Path items={['AiMesh']} />. Нужен только если узлов больше одного. Обычно сюда добавляют то, что стоит на месте и плохо переносит переключения: умные колонки, принтеры, телевизоры. {{ className: 'lead' }}

  Чёрный список роуминга, roaming deny list. Привязать устройство к одному узлу у ASUS можно отдельной функцией Bind.

## Roaming Block List

<Fields>
  <Field name="Enable roaming deny list" aka="запрет роуминга" options={['Yes', 'No']}>
    Включает список. Без AiMesh ничего не меняет. AiMesh перестаёт сам перебрасывать эти устройства, но устройство всё равно может перейти к другому узлу по своему решению.
  </Field>
  <Field name="Client Name (MAC Address)" kind="text" example="имя или MAC">
    Устройство, которое останется на своём узле. Добавляется кнопкой <K>+</K>, удаляется <K>−</K>.
  </Field>
</Fields>
