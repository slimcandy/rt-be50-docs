# LAN - IPTV

Настройки для телевидения от провайдера (IPTV). Нужны, если провайдер показывает ТВ через приставку или multicast. Смотрите ТВ через приложения и сайты — ничего здесь не трогайте. {{ className: 'lead' }}

Какие значения нужны, знает только ваш провайдер: номер VLAN, порт для приставки. Ищите инструкцию на его сайте по запросу «IPTV ASUS» и названию провайдера. Роутер поддерживает только одну услугу IPTV.

## Special Applications

<Fields>
  <Field name="Enable multicast routing" aka="IGMP proxy" options={['Disable', 'Enable']}>
    Пропускать multicast‑поток ТВ из сети провайдера в домашнюю сеть, к телевизору или компьютеру без приставки.
  </Field>
  <Field name="Default IGMP version / Default MLD version" options={['IGMP v1', 'IGMP v2', 'IGMP v3']}>
    Версия протокола подписки на поток. Появляется при включённом multicast. Нужную версию подскажет провайдер; в документации ASUS по умолчанию v3.
  </Field>
  <Field name="Enable Fast Leave" options={['Disable', 'Enable']}>
    Быстрее отключать поток, когда переключили канал.
  </Field>
  <Field name="Enable efficient multicast forwarding (IGMP Snooping)" aka="IGMP Snooping" options={['Disable', 'Enable']}>
    Отправлять поток только тем устройствам, которые его смотрят, а не всем подряд. Для Wi‑Fi то же самое включается отдельно для каждого диапазона в <Path items={['Wireless', 'Professional']} />.
  </Field>
  <Field name="UDP Proxy (Udpxy)" aka="udpxy" kind="text" example="0">
    Превращает multicast‑поток в обычный HTTP, чтобы смотреть ТВ на телефоне или в плеере. Здесь вписывают номер порта, `0` — выключено. С портом `4000` адрес канала в плейлисте выглядит как `http://192.168.50.1:4000/udp/адрес:порт`.
  </Field>
</Fields>
