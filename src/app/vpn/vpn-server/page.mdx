# VPN - VPN Server

Роутер становится VPN‑сервером: с телефона или ноутбука в чужой сети вы попадаете домой, как будто подключены к домашнему Wi‑Fi. Это безопасный способ добраться до NAS или камер и выйти в интернет через домашнее подключение. {{ className: 'lead' }}

<Note>
  Серверу нужен белый (публичный) адрес. Если роутер стоит за другим роутером или за NAT провайдера (WAN IP в <Path items={['Network Map']} /> начинается с `10.`, `100.64`–`100.127`, `172.16`–`172.31` или `192.168.`), снаружи до него не достучаться, пока на вышестоящем устройстве не пробросить порт.
</Note>

<HowToSearch queries={['asus wireguard сервер настройка', 'wireguard или openvpn что выбрать', 'pptp небезопасен']}>
  VPN‑сервер, удалённый доступ к домашней сети, remote access VPN. Устройство, которое подключается, называют клиентом или пиром (peer).
</HowToSearch>

## Типы серверов

<Fields>
  <Field name="WireGuard VPN" aka="WG" kind="info" example="рекомендуется">
    Современный, быстрый, мало нагружает роутер. Роутер сам создаёт настройки для клиента: файл или QR‑код для приложения WireGuard. Порт виден в поле <K>Listen Port</K>.
  </Field>
  <Field name="OpenVPN" aka=".ovpn" kind="info">
    Проверенная классика, если устройство не умеет WireGuard. Клиенту выдают файл `client.ovpn` (кнопка <K>Export</K>); после каждого изменения настроек файл нужно выгрузить заново. По умолчанию клиенты получают доступ только к домашней сети, без выхода в интернет через дом.
  </Field>
  <Field name="IPSec VPN" aka="IKEv2" kind="info">
    Работает со встроенным VPN в iPhone, Android и Windows без отдельных приложений. Вход по общему ключу (<abbr title="Pre-Shared Key, общий ключ">PSK</abbr>) и логину; до 8 учётных записей. На нём же работает <Path items={['VPN', 'Instant Guard']} />.
  </Field>
  <Field name="PPTP" kind="info" example="не включать">
    Устаревший и взломанный протокол: Microsoft ещё в 2012 году рекомендовала от него отказаться. Не включайте.
  </Field>
</Fields>
