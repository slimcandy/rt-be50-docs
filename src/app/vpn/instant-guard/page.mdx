# VPN - Instant Guard

VPN домой в одно касание: приложение ASUS Instant Guard на телефоне подключается к роутеру по IPsec (IKEv2) без ручной настройки. Это упрощённая обёртка над <Path items={['VPN', 'VPN Server']} />. {{ className: 'lead' }}

Что нужно: белый адрес у роутера, заранее настроенное приложение ASUS Router с включённым удалённым доступом. Работает только по IPv4, до 8 устройств. За другим роутером на нём пробрасывают порты UDP 500 и 4500 и TCP 8443.
