# System Log - Wireless Log

Устройства, подключённые по Wi‑Fi, по диапазонам: MAC, уровень сигнала (<T>RSSI</T>), скорость, стандарт Wi‑Fi. Удобно, чтобы понять, почему устройство в дальней комнате тормозит. {{ className: 'lead' }}

Сигнал в dBm: чем ближе к нулю, тем лучше. Около −50 — отлично, −70 — терпимо, ниже −80 — связь будет рваться.
