# System Log - General Log

Системный журнал: запуск роутера, подключение к провайдеру, выдача адресов, ошибки. Сверху видно текущее время роутера и сколько он работает без перезагрузки. {{ className: 'lead' }}

## System Log

<Fields>
  <Field name="Clear / Save / Refresh" aka="очистить, сохранить, обновить" kind="info" example="Save">

  <Field name="Remote Log Server / Remote Log Server Port" aka="удалённый сервер журнала" kind="text" example="IP · 514">

Что искать: повторяющиеся неудачные входы в роутер (кто-то подбирает пароль), частые обрывы связи с провайдером, ошибки зашифрованного DNS.
