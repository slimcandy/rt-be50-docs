# IPv6

IPv6 — новая версия интернет‑адресов. Если провайдер её даёт, устройства получают «настоящие» адреса без <T>NAT</T>. Если не даёт, оставьте <K>Disable</K>, ничего не потеряете. {{ className: 'lead' }}

<Note>
  С IPv6 часть трафика и DNS‑запросов может пойти в обход настроек, сделанных только для IPv4: мимо DNS‑фильтра или мимо VPN. Включили IPv6 — проверьте, что фильтр и VPN по‑прежнему работают (см. <Path items={['Справочник', 'Приватность и безопасность']} />).
</Note>

<HowToSearch queries={["asus как настроить ipv6", "slaac или dhcpv6", "test-ipv6"]}>
  Нативный IPv6, проброс (Passthrough), туннели 6in4/6rd, делегирование префикса (DHCP‑PD), SLAAC, DHCPv6, RA (Router Advertisement).
</HowToSearch>

## Basic Config

<Fields>
  <Field name="Connection type" aka="тип подключения IPv6" options={['Disable', 'Native', 'Static IPv6', 'Passthrough', "FLET'S IPv6 service", 'Tunnel 6to4', 'Tunnel 6in4', 'Tunnel 6rd']}>
    <K>Native</K> — провайдер даёт IPv6 напрямую, самый частый случай; при PPPoE выбирают его, IPv6 идёт через ту же сессию. <K>Passthrough</K> — роутер пропускает IPv6 насквозь, без своих функций. Туннели нужны, когда провайдер IPv6 не даёт, а он нужен вам; <K>Tunnel 6to4</K> устарел, его не берите. Что выбрать, подскажет провайдер. В режиме точки доступа IPv6 не настраивается.
  </Field>
  <Field name="Interface" options={['PPP', 'Ethernet']}>
    Откуда брать IPv6: из PPP‑подключения (если интернет по <abbr title="Point-to-Point Protocol over Ethernet">PPPoE</abbr>) или напрямую с порта.
  </Field>
  <Field name="DHCP-PD" aka="prefix delegation, делегирование префикса" options={['Enable', 'Disable']}>
    Провайдер выдаёт роутеру целый блок адресов для домашней сети.
  </Field>
</Fields>

## LAN Setting

<Fields>
  <Field name="Auto Configuration Setting" aka="SLAAC, DHCPv6" options={['Stateless', 'Stateful']}>
    <K>Stateless</K> — устройства сами придумывают себе адреса (SLAAC), так понимают все. <K>Stateful</K> — адреса раздаёт роутер (DHCPv6), его не поддерживает Android.
  </Field>
  <Field name="Connect to DNS Server automatically" aka="DNS IPv6" options={['Enable', 'Disable']}>
    Брать IPv6‑DNS у провайдера. Если у вас настроен DNS‑фильтр, проверьте, что устройства не получают DNS провайдера в обход роутера.
  </Field>
  <Field name="Enable Router Advertisement" aka="RA" options={['Enable', 'Disable']} recommended="Enable">
    Роутер объявляет себя шлюзом IPv6. Без этого IPv6 в домашней сети не заработает.
  </Field>
</Fields>
