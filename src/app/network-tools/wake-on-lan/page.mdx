# Network Tools - Wake on LAN

Включает компьютер по сети: роутер отправляет «волшебный пакет» на MAC‑адрес сетевой карты. Компьютер должен быть подключён кабелем, а Wake on LAN — включён в его BIOS или UEFI и в настройках сетевой карты. {{ className: 'lead' }}
