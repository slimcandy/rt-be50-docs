## Network Analysis

<Fields>
  <Field name="Method" options={['Ping', 'Traceroute', 'Nslookup']}>

<K>Nslookup</K> для рекламного домена — быстрый способ проверить, что DNS‑фильтр роутера работает: в ответ придёт `0.0.0.0` или пусто. Это проверка самого роутера. Устройство, у которого DNS вписан вручную, может ходить мимо.
