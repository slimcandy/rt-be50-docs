# Firewall - URL Filter

Блокировка сайтов по слову в адресе: впишите `XXX`, и закроются `abcXXX.com`, `XXXbbb.com` и так далее. Действует на всю сеть сразу, отдельно для одного устройства не настраивается. {{ className: 'lead' }}

<Note>
  Фильтр срабатывает на запросах имён (DNS) к роутеру. Устройство, на котором включён свой зашифрованный DNS (DoH или DoT в браузере или в системе), его обходит. Чтобы закрыть «один сайт для всех», этого хватает; как защита от детской изобретательности — нет.
</Note>
