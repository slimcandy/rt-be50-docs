# Firewall

Файрвол роутера: не пускает в домашнюю сеть подключения из интернета, о которых никто изнутри не просил. Включён по умолчанию, так и оставьте. {{ className: 'lead' }}

## Basic Config

<Fields>
  <Field name="Enable Firewall" options={['Yes', 'No']} recommended="Yes">
    Главный выключатель файрвола.
  </Field>
  <Field name="Enable DoS protection" aka="защита от DoS" options={['Yes', 'No']}>
    Ограничивает поток подозрительных пакетов: попыток соединения, проверок портов, ping. По умолчанию выключено. Включить безопасно, если роутер виден из интернета с белым адресом.
  </Field>
  <Field name="Logged packets type" aka="журнал пакетов" options={['None', 'Dropped', 'Accepted', 'Both']} recommended="None">
    Что записывать в <Path items={['System Log', 'General Log']} />. <K>Dropped</K> — для отладки.
  </Field>
  <Field name="Respond ICMP Echo (ping) Request from WAN" aka="ответ на ping из интернета" options={['Yes', 'No']} recommended="No">
    Отвечать ли на ping из интернета. Выключено по умолчанию: так роутер чуть менее заметен для сканеров.
  </Field>
</Fields>

## Inbound Firewall Rules (IPv4)

<Fields>
  <Field name="Enable IPv4 inbound firewall rules" aka="входящие правила" options={['Yes', 'No']}>

## IPv6 Firewall

<Fields>
  <Field name="Enable IPv6 Firewall" options={['Yes', 'No']} recommended="Yes">

  </Field>
  <Field name="Famous Server List / правило" aka="входящие правила IPv6" kind="text">
