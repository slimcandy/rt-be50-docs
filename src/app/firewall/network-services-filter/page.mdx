# Firewall - Network Services Filter

Запрещает устройствам дома обращаться в интернет на определённые порты или адреса, по расписанию или всегда. Главное домашнее применение — не дать устройствам ходить к чужим DNS‑серверам в обход фильтра роутера. {{ className: 'lead' }}

<Note tone="bad">
  В режиме <K>Allow List</K> вне выбранного расписания интернет пропадает у всех устройств сразу. Начинайте с <K>Deny List</K>.
</Note>

## Пример: весь DNS только через роутер

В режиме <K>Deny List</K>, расписание — всегда, <K>Source IP</K> и <K>Destination IP</K> пустые:

| Port Range | Protocol | Что закрывает |
|---|---|---|
| 53 | UDP | Обычный DNS к чужим серверам в обход роутера |
| 53 | TCP | То же по TCP |
| 853 | TCP | Зашифрованный DNS (DoT), вписанный вручную, например «Частный DNS» на Android |

Роутер при этом спрашивает DNS сам, и правило его не касается, а устройства спрашивают роутер. Зашифрованный DNS через HTTPS (DoH, порт 443) так не закрыть: порт тот же, что у всех сайтов. Его закрывают списком DoH‑серверов в DNS‑фильтре (например, в AdGuard DNS).
